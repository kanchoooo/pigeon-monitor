비둘기 모니터
자리를 비우면 내 화면에 비둘기가 날아와요 🕊
모이를 주고, 쫓아가서 생포하고, 네컷으로 자랑해요.
⬇ 맥용 다운로드
macOS 11 이상 · 애플 실리콘 / 인텔 모두 지원
  1. 받은 PigeonMonitor-mac.dmg 파일을 열어요.
  2. 비둘기 모니터 아이콘을 응용 프로그램 폴더로 끌어다 놓아요.
  3. 응용 프로그램(Launchpad)에서 비둘기 모니터를 실행해요.
  4. 1분 동안 마우스·키보드에서 손을 떼면 비둘기가 날아와요. 바로 보고 싶으면 지금 부르기!
💡 창을 닫아도 메뉴 막대(오른쪽 위)에 비둘기 아이콘으로 남아 있어요. 화면 기록 같은 권한은 필요 없어요.
⬇ 윈도우용 다운로드
Windows 10 / 11 (64비트)
  1. 받은 PigeonMonitor-Setup.exe 를 실행해요.
  2. 파란 창 “Windows의 PC 보호”가 뜨면 추가 정보를 누르고 실행을 눌러요.
  3. 설치가 끝나면 비둘기 모니터가 자동으로 열려요.
  4. 1분 동안 마우스·키보드에서 손을 떼면 비둘기가 날아와요. 바로 보고 싶으면 지금 부르기!
💡 “PC 보호” 창은 새로 나온 프로그램이라 뜨는 거예요. 추가 정보 → 실행을 누르면 설치돼요.
창을 닫아도 작업 표시줄 오른쪽 트레이(^)에 비둘기 아이콘으로 남아 있어요.
